# Portafolio de Carlos Orlando Meneses Corona

Sitio personal publicado en [GitHub Pages](https://orlandocorona.github.io/). El código editable está en `site/` y las imágenes y el CV están incluidos en el repositorio.

## Desarrollo

Requisitos: Node.js y npm.

```bash
cd site
npm install
npm run dev
```

Para actualizar el sitio publicado, ejecuta `npm run build` dentro de `site/`, copia el contenido de `site/dist/` a la raíz del repositorio y sube los cambios a la rama `main`. GitHub Pages publica los archivos de la raíz.
